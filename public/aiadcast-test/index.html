이전 aiadcast Dev가 설치되어 있다면

기존 앱에서 작업을 프로젝트 백업으로 외부 폴더에 저장한 후 aiadcast Dev를 삭제하고 새로 설치해주세요. 이전 개발 서명과 달라 덮어쓰기가 불가능합니다. 백업하지 않은 앱 내부 데이터는 삭제 시 사라집니다. 기존 외주 앱은 삭제하지 않아도 됩니다.

이번에 확인할 기능

  • 사진·상품 설명 → 분위기 → 비율·연락처의 3단계 제작

  • 회사명·전화·이메일·홈페이지 표시 옵션
  • 직접 편집, 프로젝트 백업, PNG 저장
