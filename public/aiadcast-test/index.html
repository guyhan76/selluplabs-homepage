이번에 확인할 기능

  • 사진으로 광고를 만드는 활용 과정을 보여주는 한국어 메인 화면
  • 실물·규격 상품 / 서비스 → 카테고리 → 세부 업종 선택
  • 사진·상품 설명 → 분위기 → 비율·연락처의 3단계 제작
  • 참조사진 최대 10장 선택
  • 광고 만들기 첫 단계에서 회사명·전화·이메일·홈페이지 입력 및 개별 표시 선택
  • 직접 편집, 프로젝트 백업, PNG 저장

휴대폰 AI 생성은 공개 서버 연결 전이라 사용할 수 없습니다. 이 파일은 Google Play 출시용이 아닌 개발 테스트 앱입니다.
