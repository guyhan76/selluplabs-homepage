## 기능

반응형 레이아웃, 한국어·영어 전환, 분야별 필터, 더 보기, 이미지 확대·이전/다음·키보드 조작, 사례명을 넣은 문의, 전화 연결, 이메일 문의, 모바일 고정 문의 버튼, FAQ.

문의 양식은 **이메일 앱을 여는 방식**입니다. 사이트 서버에 저장하거나 자동 발송하지 않습니다. 방문자가 이메일 앱에서 보내기를 눌러야 발송됩니다. 실제 주문·가격·납기·최소 수량은 상담으로 확인하도록 안내합니다.

## 유지보수

소스는 [`previews/younghwa`](../../previews/younghwa)에 있습니다. 루트 홈페이지 앱과 aiadcast 코드는 변경하지 않았습니다. 정적 파일이라 운영 배포 시 해당 폴더를 독립 사이트로 사용할 수 있습니다. 공개 전 `noindex,nofollow` 제거와 도메인·메타 정보 설정을 별도로 진행합니다.

```sh
# 저장소 루트에서 실행
python3 -m http.server 4192 --bind 127.0.0.1 --directory previews/younghwa
node previews/younghwa/tools/verify.mjs
node previews/younghwa/tools/package.mjs
```

검증 스크립트는 기존 저장소의 Playwright·axe 의존성과 `/usr/bin/chromium`을 사용합니다. 프로젝트 셋업 변경이나 환경 재게시가 필요하지 않습니다. 실행 가능한 서버 프로세스는 매 작업마다 다시 시작합니다.

이전 aiadcast 개발은 `guyhan76/aiadcast-next`의 `feat/mobile-private-beta-20261010`, 커밋 `eb71e86`에 저장되어 있으며 이번 홈페이지 작업으로 변경하지 않았습니다.

## 독립 도메인용 배포 파일

[Cloudflare 정적 사이트 업로드 ZIP](younghwa-cloudflare-upload.zip)은 루트에 index.html이 있는 독립 사이트입니다. 별도 Pages 프로젝트에 업로드한 뒤 해당 프로젝트에 새 도메인을 연결할 수 있습니다. 기존 셀업랩스 도메인을 영화패키지 전용 도메인으로 바꾸지 않습니다.
